# Project Specification

## Name
Kalkulator

## Purpose
A polished, reliable calculator application for Android built with web technologies and Capacitor.

## Technology
- TypeScript
- React
- Vite
- Capacitor
- Android Gradle project
- npm

## Core Features
- Addition, subtraction, multiplication, division
- Decimal input
- Percentage
- Sign toggle
- Clear and backspace
- Correct operator precedence
- Repeated equals behavior, if supported
- Keyboard support on web
- Calculation history (optional; local storage only)
- Responsive interface
- Light and dark theme, if included

## Platforms
- Android APK
- Browser development preview

## Privacy
- No account required
- No analytics by default
- No unnecessary network requests
- No unnecessary Android permissions
- Calculation history remains local unless the user explicitly enables an appropriate export feature

## Out of Scope
- Covert monitoring
- Reading other applications' private data
- Hidden camera or microphone access
- Background surveillance
- Privilege or permission bypasses
