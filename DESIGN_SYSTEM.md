# Design System

## Design Direction
Create a distinctive, premium calculator UI. It should feel intentional, polished, modern, and native to mobile. Avoid generic AI dashboard aesthetics.

## Design Process
1. Use UI/UX Pro Max to explore suitable styles and palettes.
2. Define a clear visual concept before implementation.
3. Select typography with strong legibility.
4. Establish consistent spacing and button dimensions.
5. Design the display, operator buttons, numeric keypad, and utility actions as one coherent system.
6. Review actual screenshots on Android screen sizes.

## Requirements
- Strong visual hierarchy between result, expression, operators, and keypad.
- Large touch targets.
- Consistent spacing.
- Clear pressed, focus, disabled, and active states.
- Readable contrast.
- Respect Android safe areas.
- Avoid excessive shadows, gradients, borders, and decorative effects.
- Animations must be subtle and purposeful.
- Support smaller screens without clipping.

## Deliverables
- Color tokens
- Typography scale
- Spacing scale
- Component specifications
- Button states
- Light/dark mode specifications if applicable
